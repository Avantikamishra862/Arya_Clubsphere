## How to use this folder

1. Watch the [demo video](demo-video.md), then use [`demo-accounts.md`](demo-accounts.md) to log in.
2. Read [`architecture.md`](architecture.md) for packages, sessions, and URL map.
3. Open the module note that matches the code you are changing.
4. Check [`team-integration-notes.md`](team-integration-notes.md) before editing shared files (`pom.xml`, `web.xml`, `schema.sql`, navbar/sidebar).
